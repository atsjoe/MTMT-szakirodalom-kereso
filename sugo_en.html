Welcome to the MTMT Literature Search & Network Analysis Engine! This guide explains how to construct basic and systematic queries, utilize interactive filter tokens, leverage OpenAlex network exploration, and export formatted references.

1. Elevated Search Bar & Interactive Tokens

When selecting filters in the left sidebar (Author, Journal, Institution, Publication Year, or Publication Role), they are immediately projected into the main search box as visual interactive chips:

  • AUTHOR: John Doe ✕: Represents an active entity pre-filter.
  • Visual AND Badge: Clearly indicates that your free-text keywords must co-occur alongside the selected entity filters.
  • One-Click Removal: Clicking the ✕ button immediately removes the token and clears the corresponding sidebar selection.

2. Search Modes

A. Simple Search Mode

Designed for fast, Google-like querying using plain language and operators:

Operator / Syntax Example Description
Space (Implicit AND) climate change adaptation Finds publications containing all three keywords.
Exact Phrase (Quotes) "systematic review" Matches the exact, contiguous phrase in titles or abstracts.
Exclusion (Minus Sign) artificial intelligence -health Finds publications about AI, but strictly excludes articles containing "health".
Wildcard Asterisk (*) sustainab* Matches sustainability, sustainable, sustainably, etc.

B. Systematic Literature Review (SLR) Mode

Structured according to the PRISMA protocol for rigorous academic synthesis:

  • Within a Row (Synonyms): Terms separated by commas or OR operators represent alternative synonyms (e.g. AI, artificial intelligence, machine learning).
  • Between Rows (Dimensions): Each additional row represents a mandatory concept dimension joined by Boolean AND (e.g. Row 1: Concept, Row 2: Method, Row 3: Target population).
  • Cartesian Product Solver: The client engine evaluates combinations and fetches all branches concurrently without exceeding API query limits.

3. Bibliometric Network Discovery (OpenAlex Integration)

Graph-Based Literature Discovery

This module traverses the global scientific knowledge graph to discover works connected to your MTMT results:

  • Bibliographic Coupling (Related Works): Finds related international papers sharing key references in their bibliographies.
  • Co-Citation Analysis: Identifies foundational papers frequently cited alongside the target papers by third-party research literature.
  • Network Drawer & Fusion: OpenAlex works appear in the bottom drawer. Clicking + Add to Results converts their metadata into the MTMT format, allowing you to cite them together seamlessly.

4. Academic Citation & Export Engine

Once you have selected candidate publications, use the top-right export buttons:

Format Usage & Target System
Formatted HTML Instant bibliography formatted in APA (7th), IEEE, MLA, or Chicago styles for direct copy-pasting.
BibTeX (.bib) LaTeX-compatible citations with automatic double curly brace {{Case Protection}} on titles.
RIS (.ris) Compatible with Zotero, Mendeley, and EndNote (features automatic internalId injection for papers missing standard page numbers).
CSL-JSON Citation Style Language JSON format for computational bibliographic pipelines.

5. Session Management & Novelty Alerting

Save / Load Search: Save your entire workflow (keywords, filters, active tokens, SLR matrices) as a lightweight .json file on your computer.

Alerting / Novelty Check: When reopening a saved search months later, activate the "Only show new records since last save" toggle to review only newly added literature!
