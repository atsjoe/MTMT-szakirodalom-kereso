# MTMT-szakirodalom-kereso
Egyszerű és szisztematikus review stílusú szakirodalom keresés a Magyar Tudományos Művek Tárában a MTMT API-n keresztül. Szűrési lehetőségek, a keresések elmehthetők egy téma újdonságainak figyeléséhez. Egy kis nemzetközi kitekintés az OpenAlex adatbázis közös irodalomjegyzék tételeire és közös hivatkozási hálójára.
